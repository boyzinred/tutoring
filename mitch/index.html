How to add pages and sections

Edit only the PAGES list near the bottom of this file. A new group name automatically creates a new section. 

{ title: "Conjugation Practice", href: "conjugation-practice.html", group: "Helper exercises", tag: "Conjugation" },

description is optional. If you leave it out, the card still works. Keep href as a relative path when the files live together on GitHub Pages.
