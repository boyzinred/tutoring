Finding Relevant Details

Read this first

From topic → task → useful detail

The biggest trap is answering the topic instead of the exact question. A detail is useful only when it performs a job for your main point: it explains it, proves it, illustrates it, or shows its result.

5W1H+

1 · Shrink the prompt

Turn the IELTS question into a tiny task sentence. “Why is public transport important?” becomes: I must explain importance and give reasons/results. History, personal habits, or random bus facts are not automatically relevant.

Ask: What exactly must my answer prove or describe?

2 · Make one main point

Before adding details, write one sentence that directly answers the question. Then treat every next sentence as support for that sentence—not as a chance to say something else about the topic.

Main point: Public transport reduces traffic congestion.

3 · Use 5W1H as a tool, not a checklist

Who, what, when, where, why, and how are useful only when they develop your point. For IELTS, four extra functions are especially powerful: example, cause, result, comparison.

Why?Why is it true?
How?How does it happen?
ExampleWhat proves it?
ResultWhat follows?

4 · Chain, don’t jump

A strong answer usually moves one step at a time. Each new detail should answer a question created by the sentence before it.

PointIt reduces traffic.
How?One bus carries many people.
Example40 commuters can share one vehicle.
ResultFewer cars enter the city.

5 · Use the “So what?” filter

After every possible detail, ask: So what does this do for my answer? If the detail does not explain, support, illustrate, compare, or show a result, it probably belongs outside the answer.

Keyword match ≠ relevance. A sentence can mention buses and still be useless.

6 · Fast relevance checklist

A. Does it answer a sub-question from my main point?
B. Can I name its job: why / how / example / result / contrast?
C. If I delete it, does my explanation become weaker?
D. Am I adding it only because it is “about the same topic”?
